상황

온라인 쇼핑몰의 장바구니(Cart) 시스템에서 이상한 버그가 두 개 보고되었습니다.

버그 제보 1 사용자가 새 장바구니를 만들었는데(create_cart()), 다른 사용자가 이전에 담아둔 물건이 그대로 들어있다.
버그 제보 2 장바구니를 복제(duplicate_cart())한 뒤 복제본의 수량만 바꿨는데, 원본 장바구니의 수량까지 함께 바뀌어 버렸다.

starter.py에는 이 두 버그가 재현되는 코드가 들어 있습니다. 이번 형성평가는 이 버그의 원인을 이번 주에 배운 "객체 참조 모델"로 설명하고, 코드로 직접 고치는 것입니다.

진행 방법

  1. starter.py를 열고, 맨 아래 if __name__ == "__main__": 블록(관찰 코드)을 먼저 그대로 실행해 두 버그를 직접 눈으로 확인하세요.
  2. 파일 안의 TODO 1 ~ TODO 6을 순서대로 완성하세요. 각 TODO 사이에 문제 설명이 주석으로 적혀 있습니다.
  3. 코드를 전부 완성한 뒤 파일을 다시 실행해서 run_self_check()가 오류 없이 통과하는지 확인하세요.
  4. TODO 6의 서술형 질문에 주석으로 답을 작성하세요.
